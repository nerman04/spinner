# 커피 원정대 · 팀 돌림판

빌드나 외부 CDN 없이 동작하는 정적 웹 앱입니다. 기존 서버에서 `index.html`을 열거나, 프로젝트 폴더에서 `python -m http.server 8080` 실행 후 `http://localhost:8080`에 접속하세요.

- PC / 모바일 반응형 화면, 기본 2명 및 1~100명 설정
- 가중치 기반 비복원 추첨: 한 추첨 안에서 같은 사람은 다시 뽑히지 않습니다. 각 회차에 남은 사람들의 가중치 비율로 추첨합니다.
- 팀원 직접 편집 / 여러 명 추가 / 동일 가중치 적용
- 직전 당첨자 제외, 효과음, 최근 10회 기록, 결과 복사
- 기존 `wheelItems` 명단을 읽어 이전하며 원래 저장 키는 삭제하지 않습니다.
- 명단 / 설정 / 기록은 현재 브라우저에 저장됩니다. 기기 간 공유는 지원하지 않습니다. 빈 이름 등 잘못된 편집 중인 명단은 저장되지 않습니다.
- 오프라인 사용은 HTTPS 또는 localhost에서 첫 접속과 서비스 워커 설치가 완료된 뒤 가능합니다. 파일을 직접 열면 서비스 워커와 자동 복사는 제한될 수 있습니다.
- 화면 움직임 줄이기 설정을 존중합니다. 이름은 HTML이 아닌 텍스트로 처리합니다.

검증: `node --test draw-core.test.cjs`
